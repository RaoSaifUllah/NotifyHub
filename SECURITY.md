# Security
NotifyHub is under development, not approved for production use.
OWASP ASVS 5.0 Level 2 is a verification target, not a certification.
Do not include credentials, connection strings, message bodies or personal data
in reports. Before publication the owner must configure a private reporting
channel; none is currently advertised. Do not publish exploit details or secrets
through public issue templates. See document/04-Verification-and-Standards.md.
